# 🚀 Super Simple Blog System

## How to Add a Blog (2 Steps):

### 1. Create `.md` file in `posts/` folder
Just paste your raw markdown content:

```markdown
# Your Blog Title

<img src="image-url" alt="desc" width="800" />

Your content here...

## Section 1
Content...
```

### 2. Run command
```bash
add filename.md
```

## ✨ What Happens Automatically:
- ✅ **Title** - Extracted from first `# heading`
- ✅ **Description** - Generated from first paragraph  
- ✅ **Tags** - Auto-detected from content keywords
- ✅ **Read Time** - Calculated from word count
- ✅ **Date** - Today's date
- ✅ **Author** - Your name
- ✅ **Thumbnail** - First image in content

**Just paste content and run one command!** 🎉
